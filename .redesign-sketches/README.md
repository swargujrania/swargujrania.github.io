# Redesign sketches

Rough one-screen hero explorations for the portfolio redesign. Not part of the
live site. Open any HTML file from this folder in a browser (image paths are
relative to the repository) or view the PNG renders.

1. `1-day-night` — Day (work) / Night (dance, sketch, ink) split with a seam toggle.
2. `2-editorial` — Long-read "story in chapters" with arts interludes.
3. `3-movement` — Laban's four Efforts (Weight, Space, Time, Flow) as the design system.
4. `4-studio-wall` — Mixed-media board: case studies, sketches, dance, poems, filtered by lens.
5. `5-evolution` — Refined dark/crimson bento layout without fullPage.js.
